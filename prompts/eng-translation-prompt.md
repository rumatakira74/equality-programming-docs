## Правила перевода

- Американский английский; тон технической документации; для user-docs — простой язык конечного пользователя, обращение к читателю на «you», без канцелярита.
- Терминология платформы — строго по существующим английским текстам (KNOWLEDGE-ENG-1..5, README-ENG tnp): vouching, guardians, slots, demurrage, seigniorage, attestation, Eq-<hash8> и т.п. — сверять, не изобретать. Глоссарий RU→EN зафиксировать в GLOSSARY-EN.md ДО начала перевода и применять единообразно в обоих репо.
- Markdown-структура сохраняется 1:1: уровни заголовков (якоря), списки, таблицы, блоки кода, цитаты-предупреждения. Код, команды, имена полей/флагов/файлов, пути, метки (protocolVersion, v9.16, Eq-, K=3) не переводятся.
- Внутренние относительные ссылки в переводах ведут на переведённые файлы (структура зеркальная — относительные пути сохраняются); внешние ссылки и ссылки на GitHub не менять.
- Числа, версии, размеры окон (48 ч, 14 дней), пороги, проценты — без изменений; сверка фактов перевода с оригиналом обязательна.
- Спорные термины и условные места перевода — списком в FINDING-TRANSLATION-NOTES.txt (в корне ветки рядом с eng-translation/), работу не блокировать.

## Ограничения и правила

- Чекпоинты: прогресс-коммит после каждого переведённого файла; ориентир ~30 минут активной работы проверяется по меткам времени в выводах инструментов; после любого рестарта сессии — сверить живое состояние с последним коммитом ветки, отчитаться планом, ничего не повторять без сверки.
- Коммитить только eng-translation/** и FINDING-TRANSLATION-NOTES.txt; оригиналы не править; файлы > 1 МБ не коммитить; перед add проверять git status.
- Ресурсы: перевод CPU-лёгкий, сетевые запросы не нужны; при доступно < 2 ГБ — стоп, зафиксировать в FINDING-*.txt, стоп-вопрос владельцу.
- Вопросы: мандат выполняется самостоятельно по задачам и критериям; при блокере, требующем действий только владельца (системные пакеты, доступы, опасные операции), или неоднозначности с риском ошибки/напрасной работы — остановиться и задать в чате один конкретный стоп-вопрос, продолжать после ответа. В конце — только сводка.
