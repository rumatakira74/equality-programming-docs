Этот репозиторий — конспект и практическое руководство; при расхождении приоритет у спецификации.

## Статус разработки

Этапы 0–10 и мини-этапы серии 11 выполнены: спецификация → модель экономики → крипто/ядро → сеть → консенсус → Android-платформа → Flutter-приложение → закрытая тестовая сеть (эмуляторы) → симуляция 50 узлов → аудит (криптография, консенсус, защита владельца) → платформа профилей и модулей (адаптивная комиссия, проверяющая библиотека attest, redeem/pool/contribution, конфигуратор сетей, шаблоны семи профилей, карточка восстановления, i18n — пять языков: ru, en, es, pt, zh); мини-этапы серии 11: stage11-prep — формализация решений №44–№46 и эмуляторный прогон «кража → восстановление», stage11-1-fixes — фиксы находок прогона (low-s Keystore-подписей, окно челленджа UI заявляемого периода, nonce StartMigration, флаг -migrate-delay-days), stage11-2-guardians — перевыбор личных гардианов `update_guardians` (окно 48 ч, отмена PIN-only, лимит 150 вступивших в силу смен на кошелёк, экран «Гардианы» и экран согласия, прогон с демонстрацией публикации/отмены/вступления); этап 12 — recurring-профиль №8 «Абонентский ресурс» (периодная метка, сгорание на границе P+1 без сброса баланса, peer-redeem), идентификация сети `network_id = H(manifest ‖ genesis)` + `slug` + label `Eq-<hash8>`, genesis-валидация комбинаций, имена APK `equality-{global|slug}-{std|rec}-v{версия}.apk`; мини-этап 12.1 — applicationId `io.equality.<sanitized-slug>.x<hash8>`, палитра Material; мини-этап 12.2 — fingerprint-манифест (посевной круг и поставщики = публичные ключи, `address = SHA-256(fingerprint ‖ network_id)`, wire SeedMember=public_key); мини-этап 12.3 — префикс `x` в applicationId. Спека v9.16 (protocol_version 3). После этапа 12 выполнены: этап 13 (слияние сетей не реализуется — решение владельца), этап 14 (аттестация A1/A2/A12, v9.12), этап 15 (txNow-фикс времени, v9.13), этап 16 (персистентность узла), темы net-DoS (A3), UI-защиты владельца (A5/A6), audit-frontier-pass, fix-f5-f16, fuzz-debts, A8 (боевые ключи подписи APK), mint-fix (v9.14), fix-cp-threshold, fix-mint-window, fix-release-keys, a10-docs, pre-live-audit. Проверки на живых телефонах выделены в блок `8-live` и не блокируют разработку, но блокируют пилоты. Дальше — мини-тестнет на ноутбуке владельца, затем пилоты.
