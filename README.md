## Статус разработки

Этапы 0–9 выполнены: спецификация → модель экономики → крипто/ядро → сеть → консенсус → Android-платформа → Flutter-приложение → закрытая тестовая сеть (эмуляторы) → симуляция 50 узлов → аудит (криптография, консенсус, защита владельца). Проверки на живых телефонах выделены в блок `8-live` и не блокируют разработку, но блокируют пилоты. Дальше — платформа профилей и модулей (этап 10+).
